# 指摘台帳（2026-10-02 点検）

書籍『Webアプリケーションセキュリティ入門』の章立てに沿って、読み取り専用の点検を7つに分けて行った
（g1〜g7。範囲は `docs/security/README.md`）。重大度「高」はなく、「中」はすべて修正または緩和した。
修正は 2026-10-03 に正典（https://sumihajime.com）とミラーへ反映し、チャットの索引も両方で作り直した。

- 状態: **修正済み** / **緩和**（残るリスクを受け入れた）/ **受容**（あえて対応しない）/ **未対応**
- 確認: 修正ごとに「攻撃の要求が拒否される」テストと「正常な要求が通る」テストを対で置いた。
  修正前のコードで攻撃側のテストが失敗することを確かめてから直している。
- 本番での確認は、通常の利用と同じ範囲の要求だけで行った（負荷試験・総当たりはしていない）。
