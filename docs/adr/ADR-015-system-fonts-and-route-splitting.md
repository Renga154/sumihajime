# ADR-015: 日本語Webフォントをやめて端末の書体を使い、画面ごとにコードを分割する

- Status: **Accepted — 2026-09-29**
- Date: 2026-09-29
- 関連: REQUIREMENTS §17(性能)、§15.3(アクセシビリティ)、`docs/ROADMAP.md`(ポートフォリオ水準の点検)

## Context

本番を Lighthouse(モバイル・低速4G想定)で測ると、性能はトップ 58、比較ページ 54、データについて 76
だった(アクセシビリティ・ベストプラクティス・SEO は 100)。原因を切り分けるため、同じビルドから
1つずつ外して手元で測った(2026-09-29、`wrangler dev --local`)。

| 構成                                   | トップ性能 | 初回表示(FCP) | LCP   | 初回転送 |
| -------------------------------------- | ---------- | ------------- | ----- | -------- |
| 変更前                                 | 59         | 7.0秒         | 7.9秒 | 1,045KB  |
| Noto Sans JP の読み込みだけ外す        | 95         | 1.7秒         | 2.9秒 | 296KB    |
| + 画面ごとの分割・ロゴ縮小・高さの確保 | 99         | 1.5秒         | 2.0秒 | 136KB    |

日本語Webフォント(Noto Sans JP、400/500/700)は `unicode-range` で120分割済みだったが、トップだけで
55本・約650KBあった。ページに出る漢字が多いほどスライスが増えるので、分割しても数百KBは残る。

## Decision

1. **Webフォントを配信しない。** 本文は端末の日本語書体を使う。
   `'Noto Sans JP', 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'BIZ UDPGothic', Meiryo, system-ui, sans-serif`
   - Android の既定の日本語書体は Noto Sans CJK(Noto Sans JP と同じ字形)なので、見た目は変わらない。
   - iOS/macOS はヒラギノ角ゴ。Windows は BIZ UDPゴシック(UDフォント)、なければメイリオ。
     游ゴシックは Windows で細く滲みやすいので指定しない。
   - Noto Sans JP が入っている端末ではそれを最優先で使う(DADS の指定順を保つ)。
2. **トップ以外の画面は開いたときに読み込む**(React Router の `lazy`)。トップは入口なので同梱する。
   デプロイでファイル名が変わった後、古いタブで画面を移って読み込みに失敗した場合は、
   エラー画面が1分に1回まで自動で再読み込みする(`apps/web/src/lib/stale-chunk.ts`)。
3. **ヘッダーのロゴを 512px・134KB の PNG から 108px・2KB の WebP にする。** 共有カードは 512px の PNG のまま。
4. **画面全体の読み込み中は1画面ぶんの高さを確保する**(`<Loading page />`)。本文が届いた瞬間に
   画面内のフッターが下へ跳ねていた(CLS 約0.4)。

## Consequences

- 端末ごとに書体が変わる(Apple はヒラギノ、Windows は BIZ UDPゴシック)。デザインカンプとの完全一致は
  Android だけになる。想定利用者は引越し直後の細い回線で見ることが多いので、速さを優先する。
- 書体の字面の高さが変わると、インラインリンクの当たり判定の高さも変わる(ヒラギノは Noto より約3割低い)。
  `.tap-target-inline` の余白を文字サイズから計算する式に変え、どの書体でも24px以上にした。
- 回帰は `apps/web/src/fonts.test.ts`(フォントのパッケージ・`@font-face`・読み込みが無いこと)と
  `tests/e2e/tests/perf.spec.ts`(トップがフォントを1本も取りに行かないこと)で止める。
- 直リンクで分割した画面を開くと、本体のJSの後にその画面のファイルを1本取りに行く(実測で数KB〜25KB)。
