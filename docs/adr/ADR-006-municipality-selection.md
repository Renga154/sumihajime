# ADR-006: MVP対象自治体の選定

- Status: **Accepted — 2026-07-21 D-1決裁(ユーザー承認: 世田谷+江東+新宿)**
- Date: 2026-07-21
- 決裁期限: 2026-07-26(実装計画 D-1)→ 期限内に決裁完了

## Context

実装計画§5に基づき、6候補(千代田・新宿・江東・世田谷・杉並・八王子)のデータ実現性監査を実施した。事前Web調査(5自治体)、江東区本監査([research/audit-koto-13108.md](../research/audit-koto-13108.md))、機械判読データ主張の実ファイル検証([research/audit-verification.md](../research/audit-verification.md))を完了し、6軸採点([research/municipality-audit.md](../research/municipality-audit.md))を作成した。

監査で判明した計画前提との相違:

1. 杉並区の収集曜日「HTML検索ツール」は第三者SaaS「コグモ」のJSウィジェットであり、静的スクレイピング不可(代替はPDF)
2. 江東区(事前調査ではレート制限で未調査)は収集曜日CSV+分別CSV+GIF施設CSVを持ち、データ面で世田谷と同格

## Decision(Proposed)

| 役割                    | 自治体             | 根拠                                                                                     |
| ----------------------- | ------------------ | ---------------------------------------------------------------------------------------- |
| A(VS1・単身都外転入)    | **世田谷区 13112** | 採点最高(11/12)。収集曜日CSV・施設CSV・手続きページの全てが実証済み                      |
| B(子育てペルソナ・W2-3) | **江東区 13108**   | ごみ・施設データが世田谷同格(9/12、弱点は解消可能な性質)。児童手当15日特例の期限明記あり |
| C(第3形式・W3)          | **新宿区 13104**   | 総合2位(10/12)。単身・外国籍ペルソナ。HTML表+UTF-16LEで形式多様性を担保                  |
| 補欠1                   | 杉並区 13115       | ハブページは優秀だがFR-015(地区別ごみ曜日)が縮退実装になるため降格                       |
| 補欠2                   | 千代田区 13101     | データ堅実だが転入者母数が小さい                                                         |
| 除外                    | 八王子市 13201     | ごみPDFのみ・施設CSVなし・2ドメイン分裂(4/12)                                            |

計画書§5.4の暫定案からの変更は「B: 杉並→江東」のみ。

## Consequences

- 形式多様性: 収集曜日=CSV(丁目範囲)/CSV(町名×地区番号)/HTML表、エンコーディング=Shift-JIS/UTF-8/UTF-16LE → 共通スキーマとアダプタの汎用性を実証できる
- T-012(取込パイプライン)にエンコーディング自動判定と住所セル汚損(Excel日付誤変換)の例外処理が必須要件として追加
- 江東区の国保・年金・マイナンバー個別ページの監査をT-015のsource-auditで完了させる(未完了ならcoverageをpartial表示)
- RAG/取込のドメインallowlistから旧・東京共同電子申請(shinsei.elg-front.jp、DNS消失を実証済み)系を機械的に除外する
- 杉並区は Final Stage 拡張の最有力候補として調査資産を温存する

## Alternatives considered

1. **計画どおり 世田谷+杉並+新宿**: 杉並のごみ曜日をPDF手動構造化1地区に縮退して維持する案。ハブページの監査効率は魅力だが、審査基準「データ活用」の中核デモ(FR-015)が1自治体分縮退する。棄却(ただしD-1で選択可能な代替案として提示)
2. **世田谷+新宿+千代田**: 全candidate調査済みで監査コスト最小だが、千代田のペルソナ実証力(転入者母数)が弱く、収集曜日もPDFのみ。棄却
3. **江東をAに昇格**: データ面は同格だが手続きページの一部が未確認でVS1(W1)の速度リスクになる。棄却
