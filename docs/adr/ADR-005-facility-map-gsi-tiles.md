# ADR-005: 施設地図と地理院タイルの利用

- Status: **Accepted — 2026-07-23(Wave3 着手時に利用条件を実検証し採用)**
- Date: 2026-07-23
- 関連: 実装計画 §6 ADR-005(地図・住所解決。地図はP1・着手時に利用条件の検証タスク付き)

## Context

実装計画のADR-005で、施設はMVPでは一覧表示、地図はP1(採用時 MapLibre GL JS + 地理院タイル。**利用条件・出典表示の確認は未了 — P1着手時の検証タスク**)と定めていた。Wave3で地図を着手するにあたり、まず地理院タイルの利用条件を一次情報で検証した(勝手に進めず、確認が取れなければ地図をスキップする方針)。

## 検証結果(2026-07-23 実取得)

以下を実際に取得して確認した。

1. 地理院タイル一覧: <https://maps.gsi.go.jp/development/ichiran.html>
2. 国土地理院コンテンツ利用規約: <https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html>
3. 地図の利用手続(測量法): <https://www.gsi.go.jp/LAW/2930-index.html>

確認できた要点:

- **利用手続(申請)の要否**: 地理院タイルを「ウェブサイトやソフトウェア、アプリケーション上でリアルタイムに読み込んで利用する場合」は、**出典の明示のみで申請不要**で利用できる(一覧ページの明記)。本サービスはブラウザからタイルをリアルタイム読込するこの形態に該当する。
- **出典表示の要件**: 「国土地理院」または「地理院タイル」等と出典を記載する。コンテンツ利用規約でも「出典を記載してください」とされ、編集・加工した場合はその旨も併記する。本サービスはタイルを加工せず背景表示するのみ。
- **標準地図タイルのURLテンプレート**: `https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png`(基本測量成果=標準地図)。
- 「地理院地図」「地理院タイル」は国土地理院の登録商標。出典表記には一覧ページへのリンクを付す。

以上より、**出典を明示すれば申請不要で利用可**と確認できたため、地図を実装する。

## Decision

- 地図ライブラリは **MapLibre GL JS**(`maplibre-gl`)を npm 依存としてバンドルする(CDN 不可の制約に適合)。
- 背景タイルは **地理院タイル(標準地図 `std`)** をラスタソースとして読み込む。
- 出典表示「地理院タイル」を地図隅に常時明記し、一覧ページ(ichiran.html)へリンクする。WebGL 初期化の成否に依存しない静的オーバーレイで実装し、出典が消えないようにする。
- 実装: `apps/web/src/components/FacilityMap.tsx`。座標(lat/lng)を持つ施設のみマーカー表示し、クリックで名称・住所・カテゴリのポップアップを出す。
- **プライバシー(FR-013)**: 距離計算・最寄り判定・現在地取得はしない。タイル取得は公共タイルサービスへの外部リクエストになるが、送信するのは選択済み施設の座標に基づくタイル座標のみで、利用者の住所・現在地・入力内容は一切送らない。
- **プログレッシブエンハンス**: `maplibre-gl` は動的 import でコード分割し、地図の初期化・タイル読込に失敗しても施設一覧は無傷のまま表示を続ける。
- **座標が無い施設**(例: 新宿区「若松町特別出張所」。公式ページに緯度経度の記載が無く捏造しない)は地図に出さず、一覧に「地図未対応(座標データなし)」の注記を添えて掲載を続ける。

## Consequences

- 外部リクエストが1経路増える(`cyberjapandata.gsi.go.jp` へのタイル取得)。この事実と根拠(公共タイルサービス・利用者住所は送らない・出典明示で申請不要)を README として残す(`apps/web/README.md`)。
- 地図の追加後も、地図なしでも成立する一覧が一次導線であることは変えない(縮退時の安全性)。
- 住所→座標のジオコーディングは引き続き行わない。座標は取込済みデータ(公式ソース由来)にあるものだけを使う。

## Alternatives considered

1. **地図を実装せず一覧のみ維持**: 利用条件が確認できなければこれを採る予定だった。今回は申請不要が確認できたため採用しない。
2. **OpenStreetMap 標準タイル(tile.openstreetmap.org)**: 公式の重量制限ポリシーがあり本番利用に不向き。地理院タイルの方が公的で条件が明確。棄却。
3. **静的地図画像の事前生成**: オフライン化できるが、施設数・自治体拡張のたびに再生成が要り運用が重い。動的タイルで足りるため棄却。
