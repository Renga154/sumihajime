# 30日の行動計画（2026-10〜11）

## 1週目: 聞き取り（実験1）

- X・note・知人・子育てコミュニティで「この1年に東京へ引越した人」を10人募集する（うち5人以上は子どもがいる世帯）。
- `validation-playbook.md` の質問5つで20〜30分ずつ話す。仮名でメモし、個人情報は残さない。
- 聞いた言葉をそのまま `00-intake/interviews/interview-{N}.md` に残す。

## 2週目: 計測の準備（実験2）

- プライバシーポリシーに「個人を特定しない操作の件数（日ごと）を数える」ことを先に書く（改定日を更新）。
- サーバーで日ごとの件数だけを数える: チェックリスト作成・`.ics` 書き出し・印刷・端末内の控えの表示・「期限を通知」ボタン。IP・端末IDは保存しない。
- 本番へ出し、数字が正しく増えることを確かめる。

## 3週目: 通知の実装（実験3）

- 期限の前日に知らせる Web Push を作る（Android・パソコン。iPhone はホーム画面への追加の案内から）。
- 通知の文面は期限と手続き名だけ。個人情報を送らない。
- 聞き取りの結果を `00-intake/interview-synthesis.md` にまとめ、Interview Gate（10人中8人が問題を挙げる・4人に行動のシグナル）を判定する。

## 4週目: 判断

- 聞き取りの結果で、`kill-criteria.md` の1に当たるかを判定する。
- 当たらなければ、2027年1〜4月の繁忙期に実験2・3の数字を集め、2027年5月にネイティブ（案C）の可否を決める。
- 当たれば、ネイティブは作らず、Web の改善と B2B（入居資料のQR）へ注力する。

## Flags

- **Yellow**: 2026年10〜12月は引越しが少ない時期で、実験2・3の数字が集まるのは2027年春。判断を急がない。
