# 市場分析 — スマホアプリ版の需要（Wave 1: A1）

根拠の詳細・出典URLは `raw/A1-market.md`。確信度: **High**（転入者数は政府統計）／**Low**（転入者のうちアプリを入れる割合・収益）。

## 1. 需要の母数：大きく、測れていて、季節が読める

- **東京都で転入届を出す人は年1,080,856人**（2025年。他道府県から451,843・都内の区市町村間465,145・国外から150,416・その他13,452）。[Data, Tier 1 — 東京都「住民基本台帳人口移動報告 令和7年」2026-02]
- うち**スミハジメの対応24自治体が866,481人（80%）**。[Estimate — 同表の合算]
- 全国は市区町村間の移動者5,190,548人＋国外から782,165人、**約597万人**。日本人の移動は8年連続で減少（2025年 −1.6%）。[Data, Tier 1 — 総務省 2025年結果]
- 他道府県から東京への転入者の**51.8%が20代**。0〜14歳は5.4%で、家族での転入は少数派。[Estimate — Tier 1 の表11から計算]
- **3〜4月に集中**（他道府県からの転入の35.6%、国内からの転入930,440人の28.7%）。最も多い月は平均の約2倍、少ない月は約0.6倍。[Data, Tier 1 ／ 倍率は Estimate]

## 3. 決定的な性質：必要な期間が短い

- 1回の引越しで手続きが要るのは**前後6〜8週間** [Assumption]。人は平均して約24年に1回しか市区町村をまたいで引越さない（移動率4.17%/年）[Data]。
- **同時に使う人は少ない**。中位の想定（年1万世帯）で**月間利用者は平均1,300〜1,700人、3〜4月の山で約3,000人、うちネイティブアプリの利用者は130〜500人**。[Estimate]
- 入れたアプリは引越しが終われば使われない。ストアの評価も利用者も積み上がりにくい。[Opinion]

## 4. 収益：アプリにしても増えない

- 広告は1世帯あたり**約0.5〜21円**。アプリのバナー（eCPM $0.10、ゲーム中心の2024年Q4データ）より、Webの広告のほうがまだ多い。[Estimate, Tier 3・古いデータを含む]
- 引越し関連の収益の実体は**取次手数料**（光回線 ¥5,000〜18,700、引越し見積もり ¥700〜1,629（一部2023年、古い）、電力 ¥600〜6,000／件（2022年、古い）。不動産会社への紹介は1入居者 ¥3,000〜「¥15,000以上」）。[Data, Tier 3]
  1世帯あたり ¥50〜500 と置くと、中位で年 ¥0.5M〜5M。**この金額は Web でもアプリでも同じ**。アプリで増えるのは、アプリだけが連れてくる利用者の分だけで、その根拠は見つからなかった。[Estimate / Assumption]
- 取次で稼ぐ形は、原則（中立・個人情報を集めない）と自治体への移管に反する。[Opinion]

## Data Gaps

- 引越しする**世帯**の公式な数、同じ市区町村内の転居の数。
- 引越れんらく帳の、日付があり、UUではない利用件数。マイナアプリと競合アプリの月間利用者数。引越し業者が見積もりサイトへ払う手数料。
- 転入者のうち、手続きのために**アプリを入れる人の割合**（直接の調査が見つからない）。
- 取次の成約率、引越しアプリの継続率。

## Flags

- **Red**: 同時利用が少なく、2つのネイティブのコードベースを利用者数で正当化できない。
- **Red**: アプリにしても収益は増えない（広告は微小、取次は Web でも同じ）。
- **Yellow**: 日本人の転入者は減少傾向。全国展開の律速はアプリではなく自治体データの整備。
- **Yellow（B2B）**: 入居の時点には既にお金が流れている（スマサポの入居者への電話は1件あたり¥7,147を年285,404件、2025年9月期、logmi 2025-11-19 [Data, Tier 2/3]。仲介会社への紹介料は1件最大¥8,000 [Data, Tier 3]）。ただし**取次をしない無料ツールには、事業者へ分けるお金が無い**（B2 Red 1）。B2B が本命というロードマップは、提供価値（問い合わせ対応の削減など）を別に示せるかにかかっている。アプリにしても B2B の提案には何も足されない。[Opinion]
- **Green**: 母数は大きく、政府統計で毎年測れ、季節も読める。
