## 1. 痛み（強い順）

1. **自分に何が必要か分からない** — 引越しの届出を「面倒」「やや面倒」と感じる人は合わせて93%（2024年・n=1,554、古い）。「自分に関係ない手続きを外してくれる」ことを評価するレビューがある。[Data]
2. **期限を逃してお金を失う** — 児童手当は遅れた月の分が戻らない、マイナンバーカードは90日で失効、転入届の14日目に慌てる投稿（2024-03、古い）。[Data]
3. **区ごとに持ち物・書き方が違う**。[Data]
4. **二度手間と待ち時間** — 練馬区は繁忙期に3時間以上。水道局アプリの引越し関連レビュー55件中23件が「結局電話した」（2022-11〜2024-12のレビュー、Web 版の終了直後で古い）。[Data]
5. **平日に行けない**。[Data]
6. **子育て世帯の損失が最も大きい**（保育・医療証・児童手当）。[Opinion]

## 2. Jobs-to-be-done

- 機能: 自分の手続きと期限だけを見たい／引越し後にお金を損したくない／区役所に1回で済ませたい／家族と同じリストを共有したい。
- 感情: 「抜けていないか」の不安を消したい。営業電話を受けたくない。

## 4. 誰がアプリを入れるか

- 最大の層は学生・新社会人（20代前半）。アプリを入れる意欲が年齢でどう違うかの新しいデータは無い（アイリッジ 2022年、古い「若い層はログインの要求でアプリを消す」のみ）。20代の約70%は iPhone。[Data + Opinion]
- **アプリにするなら対象は子育て世帯、特に転勤族**。引越し「後」の数か月続く期限（児童手当・医療証・保育）を、家族で共有して追う道具として。[Opinion — 痛みの強さと金銭的な損失から]
- ただし**この層は小さい**。他道府県から東京への転入者のうち0〜14歳は5.4%（約2.4万人）[Estimate — Tier 1 から]。1世帯の子どもを1.6人と置くと約1.5万世帯/年、対応24自治体で約1.2万世帯/年 [Estimate / Assumption]。都内間の住み替えの子育て世帯数は分からない（Data Gap）。0〜9歳は東京からの転出が上回る [Data]。SOM 2%なら年240世帯程度で、アプリの利用者はさらにその一部 [Estimate]。
- 外国人住民は Web 検索が先（100人中63人）、アプリは22人（2018年、古い）。[Data]

## 5. アプリを作る理由・作らない理由（最も強い3つずつ）

- **作る理由**: (1) 本当に必要な場面では東京の公式アプリも入れられている（水道局アプリ Android 50万+・iOS 評価6万件。ただし Web 版を閉じた後）(2) 期限順の個人用タスクアプリは高く評価される（らくらくMOVING 4.6★）(3) 家族での共有を求めるレビューが2件 [Data]。(4) 好みを直接聞いた調査はアプリ寄り: 選べるならネイティブ48.3%・Web 版7.3%、ストアに無いアプリは不安72.7%（Pentagon、2026-04・n=200・利害のあるベンダー調査）、必要なら入れる58%（System Research、2026-08・n=300、下の同じ調査）[Data, 弱・Tier 3]。
- **作らない理由**: (1) アプリとしての検索需要がほぼゼロ (2) アプリ疲れが測られている（必要なサービスでもアプリを**できれば**入れたくない27.3%・サービスを諦めることがある14.7%、System Research 2026-08・n=300。A2 が引いた alulu.com の記事と同じ1つの調査）、水道局アプリの引越し関連レビューの80%が★1で「こんなアプリ引越しの時くらいしか使わない」（2023-07、古い）(3) 全国向けの引越しアプリのインストール数は、全国の転入者約597万人（他道府県から東京へ来る日本人だけでも約40万人）に比べて極小 [Data]。レビューが褒めているのは中身（正しいリストと期限）で、それは Web で既に提供している [Opinion]。
- PWA にも弱点: ホーム画面にサイトを追加した人の**47.6%はもう使っていない**（Pentagon、弱い証拠）[Data, 弱]。

## Flags

- **Red**: アプリの検索需要がほぼゼロ。ストアでの発見は広告か公式の導線が無いと起きない。
- **Red**: アプリ疲れ（一度しか使わないアプリは消される）。
- **Yellow**: 「引っ越し やること」の検索は2023→2026年で約34%減。生成AIに置き換わりつつある可能性。[Estimate]
- **Yellow**: 季節性が強い（3月は平均の約2倍、少ない月は約0.6倍）。1人が使うのは引越しの前後6〜8週間だけ [Data + Assumption]。
- **Yellow**: ネイティブ版が狙う子育て世帯は小さく、0〜9歳は東京から転出超過。
- **Green**: 個人情報を取らない姿勢は、営業電話を嫌う利用者に効く。
