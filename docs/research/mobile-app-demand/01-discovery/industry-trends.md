# 動向・タイミング・プラットフォームの規約（Wave 1: A2）

規約の原文・出典URLは `raw/A2-trends-regulatory.md`。確信度: **High**（規約の原文）／**Medium**（東京アプリの計画。業界紙の報道で、都の原文は未確認）／**Low**（PWAの利用実態）。

## 1. 行政のデジタル化：アプリの必要性を下げ、中身の必要性は残す

- **東京アプリ（東京都）**: 約640万DL・マイナンバーカード連携約510万人（2026-05-31、都庁 2026-06-04）[Data]。DL数は11,000ポイント施策（2026-02〜2027-04、カード連携が条件）で伸びたもので、利用量は示さない。計画は**令和8年度下期（2026年10月〜）に居住地のエリア・年齢層に応じた情報のプッシュ配信**、令和9年度にAIによる個別最適化、**令和10年度以降に区市町村の手続きまで案内を順次拡大**（デジタル行政 2026-06-17、ITmedia 2026-06-04。同じ発表の報道で独立した裏づけではなく、都の原文は未確認）[Data, Tier 2]。
  → 始まるのは地域・年齢別の配信で、**引越し日から計算した個人ごとの期限の通知と重なるかは未確認**。区市町村の手続き案内は計画段階。[Opinion]
- **マイナポータル**: 転出届のオンライン化と転入の来庁予約（2023-02〜）。転入届は今も来庁が必要。全国向けの「引越し関連手続一覧」はあるが、自治体の選択も期限もカレンダーも無い。[Data]
- 自治体の公式LINEは1,788団体中約1,500。[Data]
- [Opinion] 行政の方向は「第三者のネイティブアプリ」の必要を下げ、「自治体をまたいで公式根拠つきで期限を並べる中身」の必要は当面残す。

## 3. Web でアプリに近づける手段（2025〜2026）

- iOS の Web Push は **ホーム画面に追加した場合だけ**（iOS 16.4〜）。**iOS 26 ではホーム画面に追加したサイトが既定でWebアプリとして開く**。[Data]
- ホーム画面への追加方法を知っている人は21.5%、ストアのアプリを信頼31.7%・ホーム画面のWebアプリ2.0%、選べるならネイティブ48.3%・Web 版7.3%、追加した人の47.6%はもう使っていない（Pentagon、2026-04・n=200・利害のあるベンダー調査、弱い証拠）[Data, 弱]。iOS のネイティブのプッシュ許可率は平均56.36%（Pushwoosh 2025、ベンダー）[Data, 弱]。
- Google カレンダーの URL 購読（ICS）はパソコンのブラウザからしか追加できない。ネイティブならカレンダーへ直接書ける、という小さいが本物の差。[Data]
- LINE ミニアプリは個人情報を取らない原則とぶつかり、通知には LINE の審査が要る。[Data / Opinion]

## 4. タイミング

- 3〜4月で全国の市区町村間移動の約30.6%。**2027年3〜4月の山に間に合わせるには、2027年1〜2月にはストアに出ている必要**（審査・Google の14日テスト・ストア検索への反映を含む）。間に合わなければ最初の本番は2028年春で、そのころ東京アプリが区市町村の手続き案内を始める計画。[Estimate]
- 他道府県から東京への日本人転入者は2025年に −2.4%。[Data]
- アプリ疲れ: 必要なサービスでもアプリを**できれば**入れたくない27.3%・サービスを諦めることがある14.7%（必要なら入れる58%）、ためらう理由の1位は「使わないアプリが増える」57.1%（System Research 2026-08・n=300。alulu.com の記事と同じ1つの調査）[Data, Tier 3]。

## Flags

- **Red**: Apple 4.2 の審査リスク（ネイティブ独自の機能への投資が前提になる）。
- **Yellow**: 東京アプリが2026年10月から地域・年齢別のプッシュ配信を始める。個人の期限通知と重なるかは未確認。区市町村の手続き案内は令和10年度以降の計画。
- **Yellow**: 開発者として個人名が出る／12人×14日のテスト（上の [Data] を再掲）。
- **Yellow**: ホーム画面への追加の認知が低い（iOS 26 で緩和）。
