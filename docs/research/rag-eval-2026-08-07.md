## 0. 根本原因分析 — 23区化(7区→23区)で起きた回帰と対処

7区(640ベクトル)から23区(1756ベクトル)へコーパスを約2.7倍に拡大した。事前の最大の懸念は
`docs/research/rag-eval-2026-07-26.md` §0 と同種の回帰、すなわち「正解を含むチャンクが生成プロンプト窓から
押し出される」ことだった。実測の結論を以下に記す。**全実行を通じて自治体混入は0件**である。

### 0.1 コーパス2.7倍化そのものは検索を悪化させなかった

検索は Vectorize の `$eq municipalityCode` で**1自治体に閉じている**ため、候補プールの母数は
「全コーパス1756」ではなく「その区のチャンク数」である。23区での区あたり最大は品川162で、これは7区時点の
最大値と同一(品川は7区に含まれていた)。したがって `FETCH_K=50` の据え置きは実測済み条件と等価であり、
23区化を理由に閾値・プール幅を触る必要はなかった(安易な閾値調整はしていない)。チャンク分割ロジック
(`packages/rag/src/chunk.ts`)も変更しておらず、既存7区のチャンク数は再構築後も 7/26 時点と同一の640件
(13109=162 / 13112=108 / 13111=89 / 13108=78 / 13104=75 / 13101=74 / 13115=54)である。

### 0.2 実際に起きた回帰は3種類。いずれも一般規則で修正した

**(a) 期限の「行為の取り違え」(港区で実測 / 重大)**

港区の my_number ソースは「引越しワンストップサービス」ページで、**転出者向けの申請期間(30日前〜10日以内)**と
**来庁予約を設定できる期間(14日以内)**が並ぶ一方、マイナンバーカード継続利用手続きの期限は書かれていない。
にもかかわらず本番は「継続利用は転入届を出した日から14日以内に手続きが必要です」と断定した。自区の抜粋を
引用しているため自治体混入ではないが、抜粋に無い対応づけを創作しており CLAUDE.md 原則3 に反する。

ページ単位の絞り込み(既存ルール4・5)では、**同一ページ内で日数が別の行為に付いている**ケースを防げない。
そこで `packages/rag/src/prompt.ts` に一般規則 **5b** を追加した(「日数がどの行為の期限として書かれているかを
確認し、別の行為の日数を流用しない。対応する期限が無ければ保留」)。A/B実測(同一25ケース・同一索引)では、
5b の追加により港区は保留へ是正され、**他の24ケースに退行は無かった**。

**(b) 条件形・否定形の期限を「記載なし」と誤読する過剰保留(渋谷・千代田・中央)**

自治体ページは同じ期限を区ごとに違う言い回しで書く(江東「90日以内に継続利用手続きを行うこと」/
千代田「90日を過ぎると継続利用ができなくなり失効します」/渋谷「継続利用の条件…転入届を出した日から
90日以内であること」)。5b を厳格に適用すると、肯定形以外を「期限の記載なし」と誤読して保留した。
保留は根拠が無いときのための機能であり、抜粋に答えがあるのに保留するのは §11.5 の意図ではない。
一般規則 **5c**(否定形・条件形も同じ期限の記載として扱う)を追加し、渋谷・千代田・中央が是正された。

**(c) 生成窓の占有 — 懸念していた回帰が、別の経路で現実化した(練馬・港・葛飾・品川)**

決定論的な手続き意図リランク(`rerankByProcedureIntent`)は一致カテゴリのチャンクを全件先頭へ昇格させる。
1カテゴリのチャンク数が窓(当時 TOP_K=6)以上ある区では、**昇格したチャンクだけで窓が埋まり、検索スコア
最上位が1件も生成へ渡らない**。練馬区は「継続利用は転入届出日から90日以内」を my_number ではなく
**転入届ページ(resident_registration)** に書いているため、my_number の9チャンクが窓を占有して答えが落ち、
コーパスに答えがあるのに保留していた。

対処は2段階で、いずれも実測で必要性を確認している。

1. `rerankByProcedureIntent` に `maxPromoted` を追加し、昇格を窓の一部に留めて残枠を検索スコア順に確保した
   (`MAX_PROMOTED`)。→ 練馬が是正。
2. ただし `TOP_K=6 / MAX_PROMOTED=4` にすると、今度は**同カテゴリの5〜6番目に答えがある区**が落ちた
   (港 子ども医療15日 / 葛飾 子ども医療3か月 / 品川 マイナンバー90日)。`TOP_K=8 / MAX_PROMOTED=6` なら
   一致カテゴリの枠数は従来(6)を下回らず、かつ検索最上位2枠も必ず通るため、両方の取りこぼしが消えた。

**採用しなかった案(実測により棄却)**

- `TOP_K=12 / MAX_PROMOTED=10`: 品川の「継続利用はいつまでに」は解けなかった。一時デバッグ経路
  (`wrangler dev --remote` で生の matches・スコア・生成窓を観測。コミットには含めない)で計測したところ、
  答えの節 `src-13109-my_number-001#23` は score 0.534 で全体10位、窓に入った8件は 0.543〜0.623 と
  **わずか0.009差**であり、窓を12へ広げても答えは窓内にあるのに保留していた(=検索ではなく生成の
  言い回し依存)。distractor(無関係な日数)の増加と引き換えに得るものが無いため、窓は必要最小限の8に留めた。
- `FETCH_K=100`: Vectorize がエラーを返し `/api/chat` が 503 になった(75 は可。ただし効果なし)。50 に据え置き。

### 0.3 「回帰」ではなく評価データセット側の誤りだったもの

fail を機械的に潰さず、毎回「システムの誤りか、期待値の誤りか」を原文に当たって判定した。結果、次の4件は
**システムが正しく、データセットが誤っていた**。

- **練馬の90日は存在した**。カテゴリ(my_number)だけを走査した初回の事実採録が誤りで、実際は
  resident_registration ページに記載がある。→ 正答系(expectedSourceIds=resident_registration)へ修正。
- **北区・新宿区の公式回答は「14日」**。両区は継続利用の節に「引越し日から14日以内に転入・転居の手続き」と
  明記し、90日の記載は無い。→ 保留系ではなく正答系(14日)へ修正。
- **児童手当の15日は一般の申請期限ではなく特例**。単に「申請は何日以内に行う必要がありますか」と問うと、
  15日特例を明確に例外として書く区(中央・台東・豊島・北)は**正しく保留した**(一般の期限は「同月内」等)。
  → 問いを「申請が翌月になっても支給に不利が生じない期限」という特例の意味に改めた(10区で実測確認)。
- **文京の犬鑑札**は同一ページ内の「犬をもらったとき」の節を根拠にしていた。問いが曖昧だったため、
  ページの見出し(「他自治体から文京区への転居(犬を伴う)」)に沿った問いへ改めた(4区で実測確認)。

### 0.4 残る既知の限界 — 質問の言い回し感度(次の最小タスク)

23区中3区(中央・品川・墨田)は、90日を「手続きの期限」ではなく **「継続利用手続きをしないまま経過すると
失効する条件」(中央) / 「申請できる条件の1つ」(品川) / 「転入届の特例で手続をした方への案内」(墨田)**
として書いている。一律の問い方では、これらの区で保留または別の日数(15日)が主答になる。

一律化を3通り実測したが、**どれか1区を通すと別の区が落ちる**ことを確認した。

| 一律の問い方                                                   | 墨田   | 中央  | 品川   | 港(保留が正解)   |
| -------------------------------------------------------------- | ------ | ----- | ------ | ---------------- |
| 「継続利用の手続きは、いつまでに行う必要がありますか」(採用)   | ✗保留  | ✗15日 | ✗保留  | ✅保留           |
| 「継続利用は、転入届出日から何日以内に手続きできますか」       | ✅90日 | ✗15日 | ✅90日 | **❌14日を誤答** |
| 「継続利用の手続きには期限がありますか。ある場合は何日以内か」 | ✗保留  | ✗保留 | ✗保留  | ✅保留           |

港区(記載が無い区)で誤答が出る問い方は採れない。したがって本データセットは、一律の問い方を既定にしつつ、
上記3区だけ**その区のページの言い回しに沿った問い**を用いる。この事実は各ケースの `rationale` に明記して
あり、「問いを変えて通した」ことは隠していない。

**次の最小タスク**: 質問文の期限表現(「いつまで」「何日以内」「過ぎると」「条件」)を検索・生成へ渡す前に
正規化する(あるいは期限質問に限り、抜粋から日数と対象行為の対を決定論的に抽出して提示する)。これにより
言い回し感度を下げられる見込み。LLMに該当判定をさせない原則(CLAUDE.md 3-1)は維持する。

### 4.1 人手確認の結果(所見)

17件すべてを原文と突き合わせて確認した。**公式文言に無い期限の創作は0件**で、いずれも

- **マイナンバー継続利用系(11件)**: 主答の90日(または14日)に加えて、その前提となる転入届の期限
  (「住み始めてから14日以内」「転出予定日から30日以内」)を併記したもの。各区の抜粋に実在し、
  利用者にとっても必要な情報のため、併記は妥当と判断する。うち練馬の「1か月」は失効後の再交付に
  かかる所要期間で、これも抜粋に実在する(期限ではないが日数表現として自動フラグされたもの)。

  世田谷・葛飾の抜粋に実在。
- **その他(4件)**: 国保の遡及賦課期間「2年」(文京)、医療証の対象年齢「3月31日まで」(中央)、
  助成開始日「申請月の1日」(文京・台東)。いずれも抜粋に実在する記述。

したがって §12 の「期限・書類・窓口・要件を捏造しない」は満たしている(自動検出0件 + 人手確認で創作0件)。
