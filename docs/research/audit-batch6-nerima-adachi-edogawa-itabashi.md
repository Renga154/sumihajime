# 23区拡張・第1バッチ事前監査(練馬区・足立区・江戸川区・板橋区)

読み取り専用の事前監査。プロダクトコード・データは変更していない。人口の多い順(練馬区・足立区・江戸川区・板橋区)に調査。練馬区(13120)・板橋区(13119)は2026-07-25の既存予備調査(`audit-nerima-13120.md` / `audit-itabashi-13119.md`)があるため、本レポートでは**現時点(2026-08-06)での再確認**を主とし、足立区(13121)・江戸川区(13123)は新規のフル監査を実施した。

## 調査日時・調査方法

- 調査日: 2026-08-06(単一セッション、順次調査。エージェント委譲は行わず自身でWebSearch/WebFetch/curl/CKAN APIを実行)
- 手続き系ページ: WebSearch(`allowed_domains`で各区公式ドメインに限定)→該当ページをWebFetchまたはcurlで直接取得し、最終更新日・期限記載・オンライン申請可否を確認
- オープンデータ: 東京都オープンデータカタログCKAN API(`https://catalog.data.metro.tokyo.lg.jp/api/3/action/`)。`organization_list`(98組織)を取得し`organization_show`で名寄せ、各区の組織IDを実証確認した:
  - 足立区(13121) = `t131211`
  - 江戸川区(13123) = `t131237`
  - 練馬区(13120) = `t131202`(既存調査と同じ)
  - 板橋区(13119) = `t131199`(既存調査と同じ)
  - (参考: 葛飾区 = `t131229`。当初`t131229`を江戸川区と誤認しないよう`organization_show`で二重確認した)
- 実ファイル検証: 該当CSVを`curl`で実取得し、列名・文字コード・行数・ID列や緯度経度列の充填率を`awk`等で確認
- 旧東京共同電子申請(`shinsei.elg-front.jp`)の生死は`dig`/`curl`で確認(2026-08-06時点、4区すべてでNXDOMAIN・HTTP:000=完全停止を再確認)
- 一次根拠: 各区公式サイト、`catalog.data.metro.tokyo.lg.jp`、`opendata.metro.tokyo.lg.jp`のみを採用。不動産・引越し業者まとめサイトは不採用

### 強み・弱み

**強み**: (1) P0手続きHTML(転入届14日・マイナンバー継続利用90日・国保加入14日・児童手当15日特例・犬の登録マイクロチップ分岐)がいずれも具体的な数値で確認でき、最終更新日も2025-11〜2026-07と直近。(2) ごみ収集カレンダーが令和8年度版で現行年度に対応(年度遅れなし)。(3) 独自のオンライン申請ポータル(xID対応)を運用しデジタル化投資は積極的。

**弱み**: (1) 都カタログ登録が全10件のみで施設・ごみ・手続き総覧が皆無。(2) 公共施設一覧CSV(GIF標準の窓口横断データ)がそもそも存在せず、区民事務所16か所の抽出はHTMLに頼るしかない。(3) ごみ収集日・分別のCSVが皆無。(4) 数少ない施設CSVもID・緯度経度が空欄で実質使えない。

### リスク一覧

- **R-Adachi-1**: 公共施設一覧CSVが都カタログに存在しない。窓口カテゴリはHTMLスクレイピングまたは人手構造化が前提。
- **R-Adachi-2**: ごみ収集日・分別データがCSV化されておらず、練馬区・板橋区・江戸川区と同型の「機械可読データ皆無」状態。
- **R-Adachi-3**: 数少ない施設系CSV(スポーツ施設・公営住宅・都市公園)のID列・緯度経度列がほぼ全行空欄で、座標付き地図表示や一意キー管理に使えない(opendata-gaps.md追記候補)。
- **R-Adachi-4**: 国民年金の転入時固有期限、保育園・小中学校サブページの最終更新日、子ども医療費助成の申請期限特例(15日か3か月か等)が未確認(`unknown`)。採用前に個別ページ再取得が必要。
- **R-Adachi-5**: 独自オンライン申請ポータル(`shinsei.city.adachi.tokyo.jp`)はLoGoフォームと異なるURL・UI構造を持ち、電子申請リンクの検出・分類ロジックを足立区専用に用意する必要がある(汎用パターンの使い回しが効かない)。

### 実ファイル検証の証跡

CKAN API(組織`t131237`):

```
organization_show?id=t131237 → title: "江戸川区"
package_search?fq=organization:t131237&rows=0 → count: 266
package_search?fq=organization:t131237&q=収集 → count: 0
package_search?fq=organization:t131237&q=分別 → count: 0
```

登録266件のうち大半(200件超)が公園彫刻・パブリックアートの個別写真データセット(例:「（子供像）砂遊び」「タワーホール船堀」等、各1データセットにJPEG数枚)で占められており、**件数の多さ(4区中最多)が実務データの豊富さを意味しない**ことを実データで確認した(板橋区の「標準オープンデータセット名称とAED一覧のみ」の教訓と同種)。

### 強み・弱み

**強み**: (1) P0手続きページはいずれも直接取得でき最終更新日も新しい(2025-03〜2026-08)。(2) マイナンバーカード継続利用で「14日+90日」の2条件を明確に区別して確認できた。(3) 児童手当(15日特例)と子ども医療費助成(3か月以内)という**異なる期限ルールを個別ページで確認**でき、他区の15日特例を安易に流用しない重要な反例を得られた。(4) 犬の登録・保育電子申請・小中学校転校もマイクロチップ分岐/転入予定者条件/電子申請対応が明文化。

**弱み**: (1) GIF標準の公共施設一覧CSVが都カタログに一切存在しない(4区中で最も明確な欠落)。(2) ごみ収集曜日・分別辞書CSVも皆無。(3) ゴミ集積所一覧CSVは存在するが実データ2行のみで実質使用不可。(4) 都カタログ266件の大半がパブリックアート写真データセットで、件数の多さが実務データの充実を意味しない。

### 4区共通の傾向

- **P0手続きHTMLの公式性は4区とも良好**。特に「マイナンバーカード継続利用は14日以内の転入届+90日以内の継続利用手続き」という二段階ルールが**練馬・板橋・足立・江戸川の4区すべてで確認**でき、江東区(継続利用ページ未取得でunknownだった)より明確。今回の再確認・新規調査で横展開時の共通実装(90日ルールの判定ロジック)に自信を持てる材料が揃った。
- **ごみデータ(重点カテゴリ)は4区とも0点**。江東区・世田谷区のような町名別収集曜日CSVは1区も持たない。板橋区・江戸川区は「集積所CSVはあるが実データがほぼ空」という共通パターン、練馬区・足立区は集積所CSV自体が存在しない。**ごみカテゴリはHTML/PDFスクレイピングまたは区への提供依頼が前提**になる点は4区共通の制約。
- **施設データは3段階の劣化パターンが見られた**: (1)練馬区=CSVはあるがバリアフリー等の充実度が低い、(2)板橋区=CSVはあるが実データ破損(ID列指数化・番地Excel誤変換)、(3)足立区・江戸川区=GIF標準の公共施設一覧CSVがそもそも存在しない。後者2区は他候補区と質的に異なる欠落(データ加工の問題ではなく、そもそも未整備)であり、区への確認や新規データ整備の相談が必要な可能性がある。
- **オープンデータ成熟度(都カタログ登録件数)は件数だけで判断できない**ことを江戸川区(266件中大半がパブリックアート写真)・足立区(登録10件のみ)の両極端な事例で確認した。件数ではなく`package_show`でリソースの中身を必ず確認する運用(既存の教訓、`opendata-gaps.md`)が今回も再現性をもって重要だと分かった。

### 実装順の推奨

1. **練馬区(13120)を最優先**。手続きHTML(90日ルール確定)・施設データ(GIF標準CSVあり、バリアフリー充実度は低いが機能する)・オープンデータ成熟度(79件)のバランスが4区中最も良い。ごみデータの不在は板橋・足立・江戸川と共通の弱点であり、練馬区固有のハンデではない。既存の江東区・品川区・大田区(縦切り済みと想定)に次ぐ第2ラウンドの筆頭候補として推奨。
2. **板橋区(13119)を次点**。手続きHTMLは練馬区と同水準まで確認密度が上がったが、施設CSVのデータ破損(番地情報の43%がExcel誤変換)という**実装前に区への修正依頼または自前補正が必須**な追加コストがある。この補正作業が完了するか、または補正ロジックを実装できる見込みが立ってから着手するのが望ましい。
3. **足立区(13121)・江戸川区(13123)は現時点でのMVP採用を推奨しない**。両区とも施設データ(GIF標準CSV)がそもそも存在せず、オープンデータ成熟度も低い(足立=登録10件のみ/江戸川=266件だが実務データはほぼゼロ)。手続きHTMLの質自体は良好(足立区の独自オンライン申請ポータル、江戸川区の児童手当/医療費助成の期限ルール区別など横展開に有用な発見はあった)ため、**手続きロジック(ルールエンジン)の実装優先度は高いが、施設・ごみデータをHTMLベースで独自構築する追加工数を先に見積もる必要がある**。足立区・江戸川区のどちらを先にするかは同水準(ともに4/12点)のため、人口(足立区が上位)を優先するか、区への開示請求・データ提供依頼の実現可能性で決めるのが妥当(本監査の範囲外、次のアクションとして記録)。

- **ごみカテゴリの代替設計**が4区共通で必須。CLAUDE.md原則3(根拠がない場合は推測しない)に従い、当面は「ごみ導線手続き」を公式の収集曜日PDF・検索ツールへの誘導にとどめる誠実縮退(大田区・練馬区の既存方針と同型)を4区すべてに適用することになる見込み。
