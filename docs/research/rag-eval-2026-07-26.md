## 0. 根本原因分析 — 7区化リグレッション(P24/P30/P35, A09)

7区化(索引527ベクトル)後に P30(品川マイナンバー)/P35(大田子ども医療)/A09(大田ごみ分別)が
再現的に fail していた。systematic-debugging に従い、一時デバッグ経路(`wrangler dev` の remote バインディング
経由で生の matches・スコア・LLM入出力を観測。コミットには含めない)で決定的証拠を収集した。

### 誤っていた当初仮説

「Vectorize の近似検索(ANN)がフィルタ付きクエリで再現率劣化」は **反証された**。P24/P30/P35 いずれも
対象チャンクは区フィルタ付きクエリで **rank 0**(スコア 0.61〜0.75、minScore 0.30 を大きく上回る)で返っており、
検索・区フィルタ・メタデータ索引・D1本文・sources台帳はすべて健全だった。したがって namespace 移行は不要。

### 真の根本原因 — 検索ではなく「プロンプト窓からの脱落」

答えの数値を含むチャンクが、同一ソースの近傍チャンクより埋め込み類似度がわずかに低いため、
生成へ渡す上位 `TOP_K=6` の窓から押し出されていた。

- **P35**: 「6か月…遡って資格が発生」は `child_medical-001` の1チャンクにのみ存在するが、章見出し
  「5 資格発生日」配下の短い節が、医療証発行・使い方・都外国組など無関係な内容と同じ 500〜800字チャンクに
  埋もれ、類似度が薄まって窓(6件)の 7 番手に落ち、LLM が「確認できません」を返して保留していた。
- **P30**: 「届出日から90日」は `my_number-001` の複数期限(14日/30日/90日)を併記した1チャンクにのみ存在し、
  同様に窓から脱落。窓を広げる(TOP_K↑)と、今度は 14日 を誤答したり(distractor)、P24 が別のケースで
  保留に退行するなど、単純な閾値・窓の調整では fail=0 に到達しないことを測定で確認した。

### 修正(採用 A+C の実測結果を踏まえた最終形)

- **C(採用・主効果): 見出し境界を優先するチャンク分割**(`packages/rag/src/chunk.ts` の `isHeadingLine` /
  `headingMinChars` 既定200)。番号見出し・【…】・記号見出し等で節を焦点化し、答えの節を独立した高類似度
  チャンクにする。オフライン埋め込み検証で P35「6か月」は rank 6→**1**、P30「90日」は rank 5→**0** へ上昇。
  期限文(「〜日以内」「〜か月以内」)は跨いで切らない。承認済みスナップショット原文は不変(派生データのみ)。
- **A(不採用): rerank の主カテゴリ優先充填**。当初 A(intent.ts の主カテゴリ排他充填)を実装したが、
  C 導入後は不要であることに加え、**新たな回帰を生む**ことを測定で確認した(P22 杉並マイナンバーで
  resident_registration と my_number が同点0.726となり、主カテゴリが resident 側へ反転して誤出典を引用)。
  よって A は破棄し、既存の rerank(一致カテゴリ全昇格)を維持。C 単独で P22/P30/P35/P11 すべてが
  正しい出典(my_number 等)を引用することを確認済み。
- **D(採用: A09 の裁定)**: `src-13111-waste_guide-001` の承認済み原文を確認したところ「資源物7品目」等の
  カテゴリ名のみで **「ペットボトル」の語は0件**。個別品目の分類を明記していない。したがって A09 の
  「保留期待」は正しく、期待は変更しない。代わりに、抜粋にカテゴリ一覧しか無い場合に一般常識で品目分類を
  補完しない旨のルール(prompt.ts ルール2b)を追加し、回答してしまう挙動を是正した。
- **再発防止**: `scripts/rag/src/build.ts` に upsert 後の Vectorize 処理完了ポーリング(`info` の
  processedUpToMutation 変化 + vectorCount 到達)を組み込み、索引反映前に評価する取りこぼしを防止。
