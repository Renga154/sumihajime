# オープンデータ欠落事例集

自治体が公開しているオープンデータ(CSV等)に、公式サイト上の実態と比較して
欠落・不整合が見つかった事例を記録する。同種の欠落は他区でも起こりうるため、
新規自治体データ整備時のチェック観点として参照すること。

再発防止の観点: 施設・窓口系オープンデータを取り込む際は、公式サイトの
「窓口一覧」「アクセス」等のページと突き合わせ、件数が一致するか確認する
(件数が合わない場合は本ファイルに追記の上、公式ページからの補完を検討する)。

## 1. 新宿区: 公共施設一覧CSVに若松町特別出張所が欠落

- 自治体: 新宿区(13104)
- データセット: 新宿区 GIF施設一覧CSV(`src-13104-facilities-001`,
  https://www.city.shinjuku.lg.jp/content/000399981.csv, 624データ行)
- 欠落内容: 新宿区の特別出張所は公式には10か所
  (四谷/箪笥町/榎町/若松町/大久保/戸塚/落合第一/落合第二/柏木/角筈)だが、
  本CSVには「若松町特別出張所」に該当する行が存在せず、9か所分しか
  抽出できなかった(T-016 一次整備時点)。原因はCSV側の欠落であり、
  抽出ロジックの不備ではないことを確認済み(624行全件を名称で走査し
  「若松町」を含む行が無いことを確認)。
- 確認日: 2026-07-22
- 補完方法: 新宿区公式サイトの特別出張所一覧ページ
  (`https://www.city.shinjuku.lg.jp/kanko/shisetu_1.html`、
  「区役所・出張所」)を新規取得し、名称「若松町特別出張所」・住所
  「若松町12-6」を確認。詳細ページ(`https://www.city.shinjuku.lg.jp/shisetsu/map1-14.html`)
  で郵便番号込みの住所(〒162-0056 東京都新宿区若松町12番6号)を裏取り。
  一覧ページの生HTMLを `data/sources/13104/snapshots/src-13104-facilities-002.html`
  に保存しSHA-256を記録、`docs/data-sources/registry.csv` に
  `src-13104-facilities-002` として追加(2026-07-22人手レビュー承認)。
  緯度経度は公式ページに記載が無いため設定していない(捏造回避。
  `data/normalized/13104/facilities.json` の `13104-fac-011` を参照)。

## 2. 世田谷区: ごみ分別一覧CSVの「品目」「分別区分」列の中身が見出しと逆

- 自治体: 世田谷区(13112)
- データセット: 世田谷区 ごみ分別一覧CSV(`src-13112-waste_sorting-001`,
  https://www.city.setagaya.lg.jp/documents/22308/n6_131121_garbage_separation.csv,
  787データ行、自治体標準オープンデータセット準拠を称する)
- 不整合内容: 見出し行の「品目」列に分別区分(不燃ごみ等、ユニーク17種)が、
  「分別区分」列に品目名(アイロン等、ユニーク787種)が入っており、
  **列見出しと中身が入れ替わっている**。江東区・新宿区の同種CSVは
  見出しどおり(品目列のユニーク数が多い)であることとの対比、および
  ユニーク値数の機械検証で確認(2026-07-23、Wave1-B)。
- 影響: 見出し名で機械的に列マッピングすると品目と区分が逆転した
  データが生成される。標準データセット準拠を前提とする横断利用の障害。
- 対処: 取込パーサに明示的なスワップオプション(`itemCategorySwapped`)を
  実装し、世田谷区のみ適用(`scripts/ingest/src/waste-sorting.ts` に理由込みで
  文書化)。データの中身は改変していない(列の対応付けのみ修正)。
- 教訓: 標準データセット「準拠」でも列の中身は検証が必要。ユニーク値数の
  比較は列スワップ検出の安価な機械チェックとして有効(取込チェック観点に追加)。

## 3. 杉並区: 事前調査の「区民事務所7件」を6件へ訂正(+ 本庁舎窓口がCSVに無い)

- 自治体: 杉並区(13115)
- データセット: 杉並区 公共施設一覧CSV(`src-13115-facilities-001`,
  https://www.city.suginami.tokyo.jp/documents/1345/131156_public_facility_1.csv,
  605データ行、GIF施設情報標準準拠)
- 不整合内容: 事前調査(`docs/IMPLEMENTATION_PLAN.md` §5.3)および過去の監査メモ
  (`docs/research/audit-verification.md`)は杉並の窓口を「区民事務所7件」と
  記録していたが、Step4-Aの再監査では、本CSVで名称に「区民事務所」を含む行は
  **6件**(井草・荻窪・高井戸・高円寺・西荻・永福和泉)であった。加えて、転入の
  主要窓口である**区役所本庁舎(区民課区民係窓口)の行がCSVに存在しない**
  (公共施設一覧に窓口として登録されていない)。
- 確認日: 2026-07-25
- 裏取り: 区公式の区民事務所一覧
  (`https://www.city.suginami.tokyo.jp/kusei/gaiyou/shisetsu/genre/kuyakushonado/jimusho/index.html`)
  でも区民事務所は6件であり、阿佐谷地域は本庁舎(阿佐谷南1-15-1)が直接管轄する
  構成であることを確認。事前調査の「7件」は本庁舎(区民課窓口)を1件に数えたための
  相違と判断した(捏造・水増しをせず、実データに合わせて6件へ訂正)。
- 補完方法: 本庁舎(区民課区民係窓口)の名称・住所(〒166-8570 阿佐谷南1-15-1)・
  受付時間は、区公式の区役所案内ページ
  (`https://www.city.suginami.tokyo.jp/kuyakushoannai/569.html`)を新規取得し
  `src-13115-facilities-002` として登録・補完(生HTMLを
  `data/sources/13115/snapshots/src-13115-facilities-002.html` に保存しSHA-256記録)。
  緯度経度は同ページに数値記載が無いため未設定(捏造回避)。区民事務所6件はCSVの
  緯度経度をそのまま採用。全ソースは人手レビュー未了(pending)。
- 教訓: 事前調査の件数(単一エージェント調査)は本監査で必ず実データと突き合わせる。
  窓口系は「本庁舎が施設一覧CSVに窓口として載らない」ことがあるため、区民事務所・
  出張所だけでなく本庁舎窓口の有無も公式ページで確認する。
